# App Store screenshots

Refreshed from the current Novalist UI on macOS and dedicated iOS 27 simulators,
using the fictional *The Cartographer's Daughter* demo project. These are image
files prepared for App Store Connect; creating them does not upload or release
the app.

| Set | Resolution | Images |
| --- | --- | --- |
| [Mac](images/macOS/) | 2880×1800 | 10 |
| [iPhone, medium Dynamic Island](images/iPhone%206.3/) | 1206×2622 | 10 |
| [iPhone, large Dynamic Island](images/iPhone%206.9/) | 1320×2868 | 10 |
| [iPhone, large Face ID](images/iPhone%206.5/) | 1284×2778 | 10 |
| [iPad 13-inch](images/iPad%2013/) | 2752×2064 | 9 |

Upload images in their numbered order. All are opaque 8-bit RGB PNGs. The medium and
large iPhone sets use separate native captures; the optional Face ID set frames
the large iPhone capture proportionally. The Mac set uses the app's existing
Mac App Store edition mode, without extension functionality.

The dimensions follow [Apple's screenshot specifications](https://developer.apple.com/help/app-store-connect/reference/app-information/screenshot-specifications),
checked on 2026-10-07. See [capture provenance and hashes](screenshots.json) and
[the screenshot pipeline](../../tools/screenshots/README.md) for reproduction.
The eleven documentation images are maintained in [the manual](../manual/images/).
