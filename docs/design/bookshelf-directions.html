A place for the books.

The current screen repeats shelf, project and book names, gives each project its own row, and confines the library to a narrow column. These three directions share the same sample library. Switch between them and resize the window to compare.

01 / Recommended

Open shelves

Book covers rest on continuous, understated shelves. A short shelf label is the only text above each group. The full window becomes the library.

Best for: making Novalist feel like a personal writing room.

Tradeoff: covers take space. Larger libraries need filtering or smaller covers.

02 / Most practical

Cover gallery

A responsive, continuous grid. The project name and draft stage sit below each cover. Shelves become filters instead of separate rows.

Best for: seeing more books at once and scanning across projects.

Tradeoff: efficient, but feels more like a library app than a physical shelf.

03 / Most bookish

Collected volumes

Books stand spine-out. Selecting a volume turns its cover toward you and reveals the project beside it. Quiet bookends complete the shelf.

Best for: a growing collection with a distinctive, tactile identity.

Tradeoff: rotated titles are slower to scan. Less suitable for long titles.

Keep the hierarchy; lose the repetition.

A shelf contains projects; a project contains books and a shared world. Show the books directly. Selecting one reveals its project, sibling books and World Bible. Moving a project moves all of its books. Unstarted projects get one typographic cover.

Show actions where they belong.

Keep New project, Open folder, search and Scratchpad in the toolbar. Put project organization in the selected-book panel; put shelf actions on the shelf. Single-click selects, double-click opens, and a visible Open book button supports keyboard and touch.

Use the space, without filling it with explanations.

No welcome slogan, oversized hero, repeated book title or permanent rearrangement arrows. All three directions fill the available window, keep controls visible, and scroll only the books. At wide sizes, more covers fit across; narrow windows reflow.

My recommendation

Start with Open shelves, using the gallery’s clean toolbar and shared detail panel. Keep project grouping visible through related books in that panel. Save spine-only presentation as a possible optional view once cover browsing feels right.
