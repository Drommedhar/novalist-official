# Does this scene work?

Novalist's per-scene analysis is descriptive — point of view, emotion, intensity, tags. It says what a scene *is* and never whether it works. A writer looking at a weak scene got numbers and no next move, and a judgement with no next move is marking rather than teaching.

The rubric is twelve questions you answer on the scene in front of you, with something to try attached to each.

Open a scene and find **Does this scene work?** in the Context tab of the inspector.

## Scoring

Each element has a name, a question (hover it) and a scale of one to five.

- Click a number to score. Click the same number again to clear it.
- Unscored reads as **Not asked here**, which is different from a low score. A chase scene is not failing at interiority — it is not trying, and a rubric that could not say so would score every action scene as broken.
- Score one **two or below** and the advice for it appears underneath. It only appears where it is needed: twelve pieces of advice at once would be a craft book, and nobody reads a craft book in an inspector.

## The elements

Four about the people, four about what happens, four about where and when:

| | |
| --- | --- |
| Wants something | Does the point-of-view character want something, now, that a reader could name? |
| We are inside somebody | Do we get what this is like from the inside, not only what happened? |
| It sounds like them | Would this scene read differently from another character's point of view? |
| Nobody agrees | Do the people in this scene want different things? |
| Something is in the way | Is something or somebody stopping them getting it? |
| It costs something | Does the reader know what it costs to fail? |
| Something changes | Is the situation different at the end than at the start? |
| It starts late | Does the scene start at the last possible moment? |
| It leaves early | Does the scene end before the reader is finished with it? |
| It happens somewhere | Could a reader say where this is by the end of the first page? |
| More than sight | Is anything heard, smelled, touched or tasted here? |
| It happens when | Does the reader know when this is, relative to the scene before? |

## Which scenes to open

Answering the rubric scene by scene tells you about one scene. What a revision needs is which scenes to open — a different question, and the reason filling it in is worth anything.

The [Style report](36-style-report.md) lists **Scenes worth another look**: everywhere you scored low, worst first, with a click to open each one. A scene you have not read against the rubric is not in that list. It is unread, not weak.
