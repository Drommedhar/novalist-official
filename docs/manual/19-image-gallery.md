# Image Gallery

The Gallery is a unified view of every image in your project. Reference photos, character portraits, location concept art, mood boards — all in one place, regardless of which entity (if any) they're attached to.

## Opening the Gallery

In the binder's view rail (below the chapter tree), click **Gallery** in the **World** group.

## What it shows

The Gallery lists every image in the project's image folder as a grid of cards. Each card shows a thumbnail and the image's filename. The count of listed images appears at the top right of the view.

Thumbnails are loaded lazily — large galleries fill in as you scroll.

## Filtering

The **search box** at the top filters images by filename or path (substring match). Useful when you remember "the dragon image" but not which entity you attached it to.

## Adding images

The Gallery itself is read-only — it surfaces images that already exist in the project. You add images from the **Codex**: every entity's detail pane has an image strip with two buttons:

- **From gallery** — pick an image already in the project. The picker shows the same grid as the Gallery view.
- **Import image** — choose a file with the system file picker; it is copied into the project's image folder and attached to the entity.

Images dropped into the project's image folder with a file manager also appear in the Gallery.
