Native runtime regression procedures (synthetic simulators only)

Evidence distinguishes observed test runs, not promises of future acceptance. No probe belongs in production builds.

1. Read native-acceptance.json and the exact source/probe manifests. Create a disposable checkout of the recorded base source; apply audit-control-fixed.patch for fixed fault/media tests. The patch includes the production evaluator correction and temporary controls. Original audit-control.patch reproduces the before-fix host-abort path. Never apply either to the main working tree.
2. Build with the recorded iossimulator-arm64/ad-hoc signing arguments and install on a dedicated disposable simulator. Use the prepared native renderer assets from the same source. Native builds need the complete .NET/Xcode environment from the continuation handoff.
3. Set NOVALIST_AUDIT_SIMULATOR to that simulator's UDID. Create a private temporary directory and set NOVALIST_AUDIT_STATE to it. Run prepare-native-media.py; its state files contain disposable simulator paths and must not be committed.
4. Use native-probe.py with a JavaScript expression on stdin to evaluate through the temporary real WKWebView control channel. The helper base64-encodes JSON to avoid differences in MAUI/native string encoding. audit-control-client.py writes one atomic command at a time and waits for its matching ID.
5. run-native-media.py exercises native decode, delayed source replacement, project/cache replacement, dismissal, oversized image rejection and unchanged fixture hashes through the production asset loader. It writes native-media-races-fixed.json. Synthetic DOM preview nodes do not prove all real scene/map/Research/3D UI integrations.
6. run-native-fault.py accepts evaluator-native-failure, evaluator-timeout, backend-failure or webcontent-termination. Each requires a healthy newly reloaded page. Native exception calls WebKit with a throwing script; timeout holds one evaluator task without blocking UI. Backend failure disposes the ready bridge. The real termination case verifies the app-associated WebContent process basename before killing only that PID. Never kill an unidentified WebContent process.
7. Build the standalone XCTest runner from ../simulator-ui/project.pbxproj.txt and AuditUITests.xcscheme.txt, replacing its test source with NativeReloadTests.swift. Run it against the dedicated simulator after each fault; it presses the actual native Reload button. Verify a fresh window.novalist.defaultProjectRoot() call resolves after reload. A successful control-channel eval alone is not production bridge evidence.
8. Fault runs here prove transport rejection/alert/reconnection subsets. A terminated JavaScript context cannot report promise settlement. Retained unsaved edits and mutation nonreplay still need separate original acceptance. One-shot controls and native page Reload isolated these runs, but the stricter original per-case probe-removal/rebuild requirement remains pending.
9. Remove every temporary gate/control source and restore production files, retaining only the final production evaluator correction. Compare source hashes, clear disposable build outputs, rebuild, verify code signatures and launch normal UI. final-clean-build.json and final-source-inputs.json record this run. No probe source remains in Novalist.Mobile.

M02's separate real Files-provider fixture, exact combined patch, positive native scope counters, genuine delayed picker callback and removal evidence are under m02/. UI lifecycle and real container relocation procedures are under ../simulator-ui/. Each artifact records its own exact source; do not attribute an older run to a newer source merely because the behavior appears unchanged.

Only compact sanitized evidence is committed. Private temporary paths, full XCResults, raw build logs and synthetic container backups remain local. All original physical-device requirements remain deferred under the user's simulator-only direction.
