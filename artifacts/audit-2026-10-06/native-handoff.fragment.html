Install and launch the simulator app

Create or choose a dedicated test simulator in Xcode → Window → Devices and Simulators. Copy its identifier into simulator_udid below. Use synthetic projects: this app has the existing com.novalist.app identity, so installation can replace an existing build on the selected target.

simulator_udid="REPLACE_WITH_TEST_SIMULATOR_UDID"
rid=iossimulator-arm64
[ "$(uname -m)" != x86_64 ] || rid=iossimulator-x64
dotnet build Novalist.Mobile/Novalist.Mobile.csproj -t:Run -f net10.0-ios27.0 \
  -p:RuntimeIdentifier="$rid" -p:EnableCodeSigning=true -p:CodesignKey=- \
  -p:_DeviceName=":v2:udid=$simulator_udid" -m:1 -nr:false

The Run target builds, installs and launches the selected simulator app. Use local ad-hoc signing for launch: the unsigned compile-only output failed with CODESIGNING Invalid Page because 11 bundled runtime dylibs had invalid signatures. Rebuilding the same production source with EnableCodeSigning=true and CodesignKey=- passed deep signature verification and launched successfully. The verification script intentionally remains unsigned because it checks compilation. The target and identifier syntax follow Microsoft's MAUI iOS CLI instructions.
