# Real-derived Scrivener fixture

`RealFormatting.scriv` is a minimized extract of the supplied Scrivener 3
`SampleProject.scriv`. Its binder was reduced to one untitled draft document
and one research note, while the RTF control sequences, Scrivener style markers,
`content.styles` ordering, and relevant `styles.xml` formats were retained.

It intentionally covers Unicode-with-ANSI-fallback punctuation, an em dash,
bold, italic, bullet and numbered lists, ignorable list destinations,
`$Scr_Ps`/`$Scr_H` markers, named paragraph styles, and an empty binder title.
